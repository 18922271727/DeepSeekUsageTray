# 鲸鱼图标 · 设计源文件

这个目录保存鲸鱼图标的“原始绘制数据”。以后要做新配色、新排版，请从这里出发，不要对着 PNG 重新画。

## 这张鲸鱼是怎么来的

- 2026-08-06 用 AI 图像模型（qwen-image-2.0-pro，通义万相系列）按 `prompt.txt` 里的提示词生成，尺寸 1024×1024。
- 生成时要求 #00FF00 纯色绿幕背景，方便抠图；生成后用去绿幕脚本把绿色背景去掉，得到透明底原图 `whale_source.png`。
- 由透明原图派生出：`whale.png`（512×512）、`whale.ico`（16~256 多尺寸应用图标）、`assets/logo-with-title.png`（鲸鱼 + 标题文字组合图）。

## 文件地图

| 文件 | 作用 |
|---|---|
| `prompt.txt` | 原始生成提示词。AI 重绘或换配色时，改这里的颜色描述再生成 |
| `palette.json` | 设计色板（角色 + HEX），机器可读 |
| `layout.json` | “鲸鱼在上、文字在下”的排版参数 |
| `text.txt` | 组合图里的标题文字（UTF-8） |
| `make-logo.ps1` | 从 `whale_source.png` 重新生成组合图，可改鲸鱼大小、文字颜色/字号 |
| `recolor.py` | 按调色板映射给鲸鱼整体换色（保持透明底） |
| `recolor-example.json` | 换色示例：深蓝 → 青绿色版本 |
| `recolor-gray-blue.json` | 参考图配色映射：深蓝 #3860DA / 浅蓝 #8BA5F6 / 白 #FEFEFE |

| 版本 | 说明 | 产出图 |
|---|---|---|
| 默认 | 原配色（深蓝身体 + 浅蓝肚皮 + 透明底） | `whale_source.png` |
| 参考图灰蓝版 | 按“参考.png”配色：灰底 #D8D9DA（原灰 #B2B3B6 向白色靠近一半）、鲸鱼上深蓝 #3860DA、下浅蓝 #8BA5F6、两行文字（DeepSeek / 计费工具 v0.1） | `assets/logo-gray-blue.png` |

## 怎么制作新配色

三种方式，按需求选：

1. **AI 重生成（最接近原始做法）**：复制 `prompt.txt`，把“深蓝色鲸鱼身体、浅蓝色肚皮”等颜色词改成新配色，用 qwen-imagegen 重新生成，再抠图替换 `whale_source.png`。
2. **脚本换色（保留原造型）**：写一个映射 JSON，然后运行：
   `python recolor.py whale_source.png 输出.png 你的映射.json`
   参考 `recolor-example.json`，把 `map` 里的源色改成目标色即可。
3. **重新排版**：运行 `make-logo.ps1`，可传参改文字颜色、字号、鲸鱼宽度等：
   `powershell -File make-logo.ps1 -TextColorHex "#123456" -TextSize 64`
